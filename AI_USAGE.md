# AI tools used — Lumen Leap

Lumen Leap was developed as an **AI-assisted extension** of the JetBrains Academy **Build a Game with an AI Coding Agent** project. This document is provided for competition transparency.

| Tool | How it supported the project |
|---|---|
| **ChatGPT (OpenAI)** | Gameplay brainstorming; implementation and integration of major features; debugging support; code review; test ideas; documentation and release preparation. |
| **GitHub Copilot** | AI-assisted code edits and troubleshooting during the initial course-derived scene, movement, and enemy systems. |
| **Claude (Anthropic)** | Consultation on an early enemy-model transform/collision issue; review of alternative fixes. |
| **Gemini (Google)** | Consultation and comparison of debugging approaches for an earlier enemy issue. |

## Development and verification process

The project developer defined the game direction, chose features and priorities, integrated and ran builds locally, reported defects through repeated hands-on browser playtests, checked fixes, and published the working game. AI tools helped draft and revise substantial parts of the code; **this project does not claim that every line was handwritten without assistance**.

## Relationship to the original tutorial

The starting point was the JetBrains Academy Three.js course game. The current game expands the tutorial with four environments, firefly objectives, an escape portal, a guardian companion, three-stage progression, health and scoring, cosmetic unlocks, alternate playable heroes, richer UI, and local records.

No code or game assets were copied from other competition submissions; those projects were viewed as design references only.
